# FIELD / Learning Atlas — Linux الآن → SOC لاحقًا

موقع تعليمي عربي RTL بواجهة FIELD / Operations Atlas، مصمم كمسارين مستقلين: Linux للدراسة الآن، ومرجع SOC بعد الانتهاء من Linux وCompTIA Security+.

## المنهج النهائي وأرقامه

- **93 وحدة دراسة** في 16 مرحلة.
- **75 أساسي + 16 إضافة مكملة + 2 تطبيق عملي**.
- 92 مقطعًا/فصلًا مرئيًا من **82 فيديو YouTube أصليًا مختلفًا**؛ بعض الفيديوهات الطويلة استُخدمت منها فصول محددة فقط، لذلك لا يتساوى عدد المقاطع مع عدد روابط الفيديو الأصلية.
- وقت المشاهدة المعروف: **36 ساعة و13 دقيقة و28 ثانية**، دون وقت المعامل. هناك 3 فيديوهات لا تُظهر القائمة مدتها، ومعمل Bandit يتغير حسب سرعة الحل.
- كل وحدات Linux النشطة مطلوبة وتدخل في نسبة الإنجاز. لم نترك قسم «توسع» مؤجل داخل المسار النشط.
- تفصيل العدد: 75 أساسي = 3 فصول أحمد عيد + 72 فيديو الطناني؛ 16 مكملة = 6 فيديوهات عبدالله + فصلان من Security Jordan Linux Part 2 + 8 فصول من فيديو Bash واحد؛ 2 تطبيق = تحدي عبدالله #27 + معمل Bandit.
- لذلك 92 مقطعًا/فصلًا مرئيًا تأتي من 82 فيديو YouTube أصلية مختلفة، ومعها معمل Bandit واحد خارج YouTube.

### لماذا 93 وحدة وليست 82 فيديو؟

لأن بعض الفيديوهات الطويلة مقسمة إلى فصول تعليمية محددة، مثل فصول أحمد عيد وفيديو Bash وفيديو Linux Part 2. نعدّ كل فصل مختار وحدة تعلم عند تتبعه، بينما نحسب رابط YouTube الأصلي مرة واحدة فقط. كما أن Bandit معمل خارجي وليس فيديو YouTube.

## التصنيفات

- **أساسي:** لبّ المنهج.
- **إضافة مكملة:** معلومة أو تطبيق جديد غير مكرر؛ يُدرس الآن في موضعه.
- **تطبيق عملي:** تحدٍ أو معمل تنفذه في نهاية القسم.
- المحتوى المكرر لا يظهر كدرس نشط ولا يدخل في النسبة؛ يشرح تقرير التدقيق سبب استبعاده.

## أقسام الموقع

1. **Linux الآن:** 93 وحدة مرتبة من التأسيس إلى المعمل النهائي.
2. **SOC لاحقًا:** 10 مراحل و51 خطوة مرجعية (بعد إنهاء Linux وSecurity+). يغطي المحاور الأربعة المطلوبة ويضيف SIEM وIncident Response وThreat Hunting وDetection Engineering.
3. **مراجعة المصادر:** قرارات الدمج والاستبعاد، الفهارس الكاملة للمصادر، وتوضيح التكرار.

## ملفات المشروع

- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — البحث والتصفية والتقدم والملاحظات والتصدير والاستيراد.
- `curriculum.js` — بيانات المنهج التي يقرأها التطبيق.
- `curriculum.json` — نسخة JSON مستقلة للمنهج.
- `sources.json` — فهارس المصادر وقراراتها.
- `CURRICULUM_AUDIT.md` — تدقيق كامل للـ93 وحدة وكل القوائم.
- `previews/` — صور المعاينة.

## GitHub + Vercel

1. فك ضغط ZIP.
2. ارفع محتويات مجلد المشروع إلى جذر GitHub Repository.
3. في Vercel اختر Import Git Repository.
4. إعدادات النشر:
   - Framework Preset: `Other`
   - Build Command: فارغ
   - Install Command: فارغ
   - Output Directory: `.`
5. Deploy.

لا يحتاج الموقع إلى Node أو قاعدة بيانات أو Build Step.

## تشغيل محلي

افتح `index.html` مباشرة أو استخدم:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الحفظ والتوافق

- تقدم Linux وملاحظاته وتقدم SOC وبوابة الانتقال تحفظ محليًا في المتصفح.
- Export/Import ينقل ملف JSON بين الأجهزة؛ لا توجد مزامنة سحابية تلقائية.
- يتضمن التطبيق ترحيلًا للتقدم من النسخة السابقة: يحذف درس Abdullah #23 المكرر، ويعامل مقاطع Bash الثلاثة القديمة كوحدة واحدة فقط إذا كانت المقاطع الثلاثة كلها مكتملة.
