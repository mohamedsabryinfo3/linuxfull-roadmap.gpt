# FIELD / Learning Atlas — Linux → SOC Analyst L1 → L2

موقع تعليمي عربي RTL بواجهة مخصصة بطابع Field Atlas / Operations Workspace. المشروع Static HTML/CSS/JavaScript ومجهز للنشر مباشرة على GitHub وVercel دون Node أو قاعدة بيانات أو Build Step.

## ما الجديد في التصميم
- هوية مرئية خاصة باسم FIELD / Learning Atlas بدل قالب لوحة تحكم تقليدي.
- خلفية Graphite داكنة مع Lime Signal Accent ولمسات Blue/Violet للمراحل المستقبلية.
- خط عربي أوضح وأكبر، وتباين أعلى في العناوين والوصف وبطاقات المحاضرات.
- خريطة مسار مصغرة في مقدمة الموقع تشرح Linux الآن ثم Security+ ثم SOC لاحقًا.
- لوحة تقدم واضحة وبطاقة Next Up بارزة لتحديد الخطوة التالية مباشرة.
- مراحل Linux ظاهرة كمسار متسلسل، مع أهداف ومخرجات كل مرحلة، وبطاقات محاضرات كبيرة سهلة القراءة.
- تصميم متجاوب للهاتف والكمبيوتر مع حالات Focus وحركة مخففة لمن يفضّلون Reduce Motion.

## أقسام الموقع
- **Linux الآن:** 96 درسًا نشطًا في 16 مرحلة، كل الدروس مطلوبة وتدخل في نسبة الإنجاز.
- **SOC لاحقًا:** مرجع مستقل يبدأ بعد إتمام Linux وCompTIA Security+. يتضمن Log Analysis وMITRE ATT&CK وEDR وHands-On SOC Skills، ويضيف SIEM وIncident Response وThreat Hunting وDetection Engineering.
- **مراجعة المصادر:** يعرض ما تم دمجه وما استُبعد ولماذا، مع فهارس المصادر التي تم التحقق منها.

## الملفات
- `index.html` — واجهة الموقع.
- `styles.css` — الهوية البصرية والتصميم المتجاوب.
- `app.js` — التفاعل والحفظ والتصفية والتصدير والاستيراد.
- `curriculum.js` — بيانات الدروس والمراحل والمسارين ومراجعة المصادر.
- `curriculum.json` — نسخة JSON مستقلة من المنهج.
- `sources.json` — سجل المصادر.
- `CURRICULUM_AUDIT.md` — تدقيق المصادر والقرارات.
- `previews/` — صور معاينة التصميم.

## النشر على GitHub وVercel
1. فك ضغط ZIP.
2. ارفع **محتويات مجلد المشروع** إلى جذر GitHub Repository.
3. في Vercel اختر Import Git Repository.
4. الإعدادات:
   - Framework Preset: `Other`
   - Build Command: فارغ
   - Install Command: فارغ
   - Output Directory: `.`
5. Deploy.

## التشغيل المحلي
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا من المجلد:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## حفظ التقدم
- يحفظ المتصفح تقدم Linux والملاحظات وتقدم SOC وبوابة الانتقال محليًا عبر `localStorage`.
- استخدم Export لحفظ ملف JSON، وImport لاستعادته على جهاز أو متصفح آخر.
- لا توجد مزامنة سحابية بين الأجهزة في هذا الإصدار.

## ملاحظات الدقة
- لم يتم تغيير بيانات المنهج في هذا التحديث البصري؛ التعديل يخص الواجهة والقراءة والاستجابة للشاشات.
- مدد أو فصول الفيديو غير المتاحة تظل موضحة في المنهج على أنها غير محددة، ولا تُستبدل بمدد مختلقة.
- بوابة SOC المستقبلية منفصلة عن نسبة إنجاز Linux.
